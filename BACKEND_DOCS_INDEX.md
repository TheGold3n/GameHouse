## 🎓 PREGUNTAS CLAVE RESPONDIDAS

✅ **¿Qué es este backend?**
→ API FastAPI que sirve datos de jugadores al frontend React

✅ **¿Por qué lo necesito?**
→ El frontend pasa de mock (simulado) a real (datos de servidor)

✅ **¿Cómo empiezo?**
→ Lee EXECUTION_GUIDE.md y sigue los 3 pasos

✅ **¿Dónde están los endpoints?**
→ http://localhost:8000/docs (Swagger UI interactivo)

✅ **¿Dónde están los datos?**
→ En memoria en backend/main.py (30 jugadores)

✅ **¿Qué cambió en frontend?**
→ Solo playerService.ts (ahora HTTP en lugar de mock)

✅ **¿Se pierden datos?**
→ Sí, al reiniciar backend (en memoria, no persistente)

✅ **¿Puedo usar base de datos real?**
→ Sí, próxima versión con PostgreSQL
